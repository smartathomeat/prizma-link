# Prizma Link

Lokale Home-Assistant-App von smartathome® für ausgewählte Prizma-Trockensalzgeneratoren über
Bluetooth Classic RFCOMM/SPP. Kein BLE, kein ESPHome-Proxy und keine Cloud. Die App startet mit
geschlossenen Schreibfreigaben und sendet nach einem Reconnect nur eine Statusabfrage. Details,
Pairing, Diagnose und Sicherheit stehen in `DOCS.md`.
